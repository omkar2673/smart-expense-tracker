# Smart Expense Tracker (React)

Overview

A simple React.js web application to manage daily expenses. Users can add, delete, and track transactions with a clean and responsive interface.

Features

- Add and delete transactions
- Data persistence using local storage
- Simple and user-friendly UI

Tech Stack

- React.js
- JavaScript
- HTML/CSS

Status

Initial version developed. Future improvements include charts and filtering.
